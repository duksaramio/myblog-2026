## 欧洲议会批准聊天监控1.0——711分
[帕特里克·布赖尔](https://www.patrick-breyer.de/en/eu-parliament-greenlights-chat-control-1-0-breyer-our-children-lose-out/)

欧洲议会通过了无差别大规模扫描私人通信的法案，尽管投票的多数议员实际上反对这一法案。投票结果为314票反对，276票支持，但拒绝该法案需要361票的绝对多数，最终未能达到。虽然对加密通信进行了象征性的豁免，但实际上服务提供商并不扫描加密内容。

这里的数学很讽刺。一项多数当选代表反对的法规，最终还是因为程序门槛而得以通过。前欧洲议会议员帕特里克·布赖尔称之为一场闹剧：理事会可以继续沿用旧的监控方法，而不是推进真正的儿童保护改革。永久性的聊天监控2.0谈判即将开始，布赖尔认为议会的抵制足够强大，使得永久的大规模监控无法获得多数支持。我们拭目以待。临时法规将运行至2028年。

这就是监控机制的棘轮效应。每次迭代都会进一步正常化更多的监控基础设施。临时措施会成为下一轮的基础。Hacker News 的反应如预期般激烈——加密和隐私是神圣不可侵犯的领域——但真正的斗争发生在理事会，而不是评论区。

## GPT-5.6——680分
[OpenAI](https://openai.com/index/gpt-5-6/)

OpenAI 将 GPT-5.6 从预览版升级为通用可用版本，覆盖 ChatGPT、Codex 和 API。该系列包括三个层级：Sol（旗舰版）、Terra（平衡/成本效益型）和 Luna（最快/最经济型）。预览版于6月26日发布，今日的公告则涉及实际的访问、定价和部署时间表。

基准测试结果尚可——在编程、科学和网络安全方面表现更佳——但真正的故事在于包装。此外，Pro、Business 和 Enterprise 用户通过 ChatGPT 获取 Sol。开发人员则通过 API 获取所有三个层级。Codex 的集成意味着 GPT-5.6 现已嵌入编码工作流程中，而非附加其上。OpenAI 显然正试图使其成为他们在所有控制领域内的默认引擎。

三层级模型（Sol/Terra/Luna）与每家云提供商在计算方面所做的类似——给客户在每个价格点上提供理由，以保持在生态系统中的留存。问题不在于 GPT-5.6 是否优秀——它可能确实如此——而在于定价和速率限制是否使已经在使用 GPT-5.5 的团队能够实际使用它。在迁移之前，等待使用报告。

## Show HN：18个单词——670分
[18words.com](https://18words.com/)

一个基于浏览器的每日单词挑战游戏，你面对18个单词并尝试生存。它有放松模式，字母揭示作为提示，存档过去的谜题，以及跟踪连胜记录。该网站还链接到创作者的另一款游戏，Zanagrams。

一个单词游戏获得670分确实很多。HN 社区喜欢那些执行到位且无VC资金支持的小项目，简洁的用户界面和清晰的卖点。18个单词符合这些标准。"Show HN" 格式——构建者直接展示他们的作品——仍然是该平台最好的部分之一。没有营销，没有公关周期，只是一个有人制作的东西。

更广泛的趋势：自 Wordle 以来，单词游戏一直在蓬勃发展，那些能够持续的单词游戏具有每日节奏（你每天回来，而不是一次性玩完）和社交分享机制。18个单词具备这些特点。真正的疑问是三个月后的留存率。

## ChatGPT 工作——250分
[OpenAI](https://openai.com/index/chatgpt-for-your-most-ambitious-work/)

OpenAI 推出了 ChatGPT 工作——ChatGPT 内部的一个代理，接受目标，跨你的连接应用收集上下文，将其分解为步骤，并返回完成的成果：表格、幻灯片、文档和网络应用。它基于 GPT-5.6 运行，内部使用 Codex 技术，可以自主完成复杂项目长达数小时。Codex 应用程序将合并到 ChatGPT 桌面应用程序中。独立的 Atlas 浏览器将被弃用。

这是 OpenAI 对“AI 代理只是演示，而非产品”的回应。其卖点是明确的：给它一个结果，它会生成交付成果，而不是聊天响应。早期测试者似乎使用它来完成编码之外的多步骤商业任务。插件目录中有1,400多个集成。使用是计量的——你只为代理实际执行的任务付费，而不是按消息付费。

不过，这种怀疑是有道理的。"数小时的自主工作"听起来很吸引人，直到你考虑到错误累积、长链中的幻觉以及多小时代理运行中输出质量的验证难度。Atlas 的弃用很有趣——OpenAI 建了一个浏览器，意识到代理层比浏览器外壳更有价值，将其重新整合回系统。如果运作良好，这将是一个明智的转向。

## Muse Spark 1.1——251分
[Meta AI](https://ai.meta.com/blog/introducing-muse-spark-meta-model-api/)

Meta 推出了 Muse Spark 1.1，这是来自 Meta 超智能实验室的多模态推理模型。它专为代理任务设计，具有在工具使用、计算机使用、编程和多模态理解方面的显著改进。它可以协调多代理系统，管理100万词的上下文窗口，并在自动化比点击界面更快时编写脚本。可通过新的公共 Meta 模型 API 获得。

其定位直接与 OpenAI 的代理故事竞争。Meta 声称 Muse Spark 1.1“零样本泛化”到新工具和 MCP 服务器，并能通过记忆、检索和压缩来管理自己的上下文窗口。计算机使用演示——在任务中途菜单更改时适应晚餐派对订单——是比基准测试更重要的现实场景。

Meta 的优势在于分发：如果此模型嵌入 WhatsApp、Instagram 和 Meta AI 应用中，它将通过数亿用户触及用户，而无需依赖开发人员采用。"个人超级智能"的框架是纯粹的营销，但其技术能力——特别是多代理协调和上下文管理——表明 Meta 严肃对待代理层。Meta 模型 API 的推出是真正的信号：他们想要开发者的关注，而不仅仅是消费者的演示。

## Meta 用自定义桥接芯片在新服务器中重用旧内存——261分
[Network World](https://www.networkworld.com/article/4192827/meta-reuses-old-ram-in-new-servers-with-custom-bridge-chip.html)

Meta 设计了一款名为 Vistara 的自定义 CXL（计算机扩展链接）芯片，用于在新机器中重用旧服务器的 DDR 内存。大约40%的 Meta 的数百万台服务器内存受限，而公司因为内存比服务器其他部分的寿命长约两倍，拥有大量的旧 DIMM。Vistara 芯片通过 CXL 无显著性能损失地将旧内存桥接到新服务器——这是直接插入新机器的旧 DIMM 无法实现的。

这是一项真正聪明的基础设施工程。内存价格预计到2026年底将翻倍，短缺可能持续到2027年。Meta 通过这种方式为其自己的退役硬件创造了一个次级市场，延长了内存的使用寿命，相当于一个服务器代际。CXL 标准使得这一点成为可能——它解耦了内存与传统的内存通道。

更广泛的影响：如果超大规模数据中心可以构建自定义硅片来重用组件，这将改变服务器更新周期的经济性。其他云提供商正在关注。对于数据中心基础设施领域的任何人来说，技术论文都值得一读。这可能不是一项炫目的 AI 故事，但它是一项不那么引人注目的优化，却能为 Meta 节省数亿美元。

## 蜘蛛毒液杀死胡蜂而不伤害蜜蜂——273分
[康联科学 / 奧胡斯大学](https://connectsci.au/news/news-parent/9703/Spider-venom-kills-varroa-mites-without-harming)

研究人员筛选了50种毒液（主要来自蜘蛛和蝎子），发现两种蜘蛛毒液肽——Ht1a 和 Gg1a——在局部应用时对胡蜂寄生虫有毒性，而不会伤害蜜蜂。该论文发表在《npj 药物发现》上。胡蜂寄生虫是全球蜜蜂种群的最大威胁，而当前的治疗方法（主要是合成杀虫剂）由于抗性传播而变得无效。

这是一项早期但有前景的研究。选择性是关键发现：肽类杀虫而不伤害宿主。这是你需要的可行治疗方法。筛选方法——对50种毒液进行暴力测试——与通常的计算药物发现炒作相比，显得格外直接。

然而，从“实验室毒性”到“在蜂箱中部署”之间存在巨大差距。交付机制、稳定性、成本、监管审批和实地效果都仍待解决。养蜂人需要的是他们可以实际应用的东西，而不是在受控条件下起作用的肽。但方向是正确的：生物特异性比广谱化学战争更胜一筹。

## 玻璃骨干：为什么下一场战争中军队的后勤将崩溃——206分
[现代战争研究院 / 西点军校](https://mwi.westpoint.edu/the-glass-backbone-why-the-armys-logistics-will-break-in-the-next-war/)

韦伯斯特学院的乔纳森·布坎南认为，美国陆军在过去二十年中优化了在许可环境中的后勤——不受争议的补给线、合同支持、静态基地——而这种模式现在成为大规模作战的负担。文章以巴巴罗萨行动为例，说明了战术上的辉煌如何被后勤失败所抵消，并且文章认为陆军必须摒弃在伊拉克和阿富汗养成的舒适的后勤习惯。

核心论点是合理的，但具体细节阐述得很好：在争议环境中，供应链本身成为目标。无人机、精确打击和电子战意味着补给线不再安全。从沙漠风暴行动中“铁山”方法（六个月的不间断筹备）在面对同等对手时变得不可能。陆军需要分布、韧性且部分自主的后勤——而它目前没有这些。

这篇文章值得一读的地方在于其机构批判。陆军在智力上知道这一点，但采购和条令系统却很缓慢。这篇文章本质上是一个职业军事教育论点：下一场战争将由谁能够在攻击下维持战斗力决定，而不是谁拥有最好的武器。历史一再证明这一点。

## Hy3——233分
[Tencent 混元](https://hy.tencent.com/research/hy3)

腾讯发布了 Hy3，这是一个具有295B参数的混合专家模型，其中21B参数活跃。它结合了快速和慢速思考能力，支持256K上下文，并在推理和代理任务上优于同等规模的模型。该模型从基础设施重建（2026年1月）到预览（2026年4月）再到全面发布仅用了不到六个月的时间，根据50多个产品的反馈进行了后训练扩展。

混合专家架构（21B活跃参数）是有趣的部分——你可以在推理成本接近21B的情况下获得295B模型的容量。这是 DeepSeek 等其他公司所做的相同赌注。腾讯从重建到发布的速度值得注意：一个前沿开源模型在六个月内完成发布，表明要么是资源投入巨大，要么是高效的流水线。两者兼而有之。

本周每个模型发布都强调了“代理能力”角度。OpenAI、Meta 和现在腾讯都在定位他们的模型为代理引擎，而非聊天机器人。Hy3 作为开源模型意味着它将被通常的玩家所采用——一起，本地推理堆栈和 API 提供商。它在实际中是否真的优于 Qwen 3 或 DeepSeek V3，才是关键，而基准测试本身无法解决这个问题。

## 通过线

今日首页的三个主题占据了主导地位。首先，**代理战争是真实的**：OpenAI 同日发布了 GPT-5.6 和 ChatGPT 工作，Meta 推出了 Muse Spark 1.1，腾讯发布了 Hy3——所有这些都定位自己为自主 AI 代理的平台。聊天机器人时代正式结束；每个模型实验室现在都在销售工人，而非助手。

其次，**欧盟的聊天监控投票**是唯一一个不涉及 AI 的故事，也是影响最多人直接的故事。程序操作——多数议员反对，但法案仍通过——是实际制定监控立法的典范。2028年的日落是个虚构；一旦建立，基础设施不会被取消。

第三，**基础设施比模型更重要**：Meta 的 CXL 桥接芯片用于回收旧内存和陆军的后勤批判都指向同一个真理——不那么引人注目的基础设施决定了炫酷的东西是否能真正发挥作用。你可以拥有世界上最好的 AI 模型，但如果数据中心无法负担内存或军队无法移动燃料，那都不重要。
