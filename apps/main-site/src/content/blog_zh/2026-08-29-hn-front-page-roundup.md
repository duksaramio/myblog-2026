## htmx 4.0.0 发布 —— 786 点

htmx 团队在八个月的开发后发布了版本 4.0，主要的改动是将 XMLHttpRequest 从内部重写为 `fetch()`。从用户的角度来看，2.x 版本的行为差异是故意最小化的——团队花费了大量时间重新发现旧实现为何以这种方式工作，然后将这些决策向前延续。

三个重要的破坏性变更：属性继承现在是显式的（你需要添加 `:inherited` 以选择加入，取代旧的隐式 CSS 样式级联，这使每个人都感到困惑），事件名称标准化为 `htmx:phase:action` 模式，历史记录默认不使用 localStorage（而是通过回退导航重新获取，这绕过了第三方 DOM 变更引发的一系列 bug）。新功能包括通过改进的 idiomorph 算法实现的形态交换，`<hx-partial>` 标签用于更清洁的多目标更新，以及新的 `hx-live` 脚本解决方案，团队将其定位为 Alpine.js 的替代品，具有“HATEOAS 友好的响应性”。

值得注意的是，4.0 在 npm 上标记为 `next` —— 他们不会在 2027 年初之前强制升级使用未版本化的 CDN URL 的人。团队还发布了 `llms.txt` 和 `llms-full.txt` 供 LLM 消费其文档，这取决于你的视角，可能是务实的做法或时代变迁的标志。`htmax.js` 包含 htmx 与流行扩展的单个文件。

**来源：** [htmx 4.0.0 发布公告](https://four.htmx.org/announcements/2026-08-28-htmx-4.0.0-is-released)

## 具有 Inception 风格的曲面地图用于逐段导航 —— 591 点

Orbify 展示了一个导航界面，该界面将地图扭曲成 Inception 风格的曲面视角——前方的道路垂直拉伸，周围的环境则弯曲远离。这是一种专利申请（PCT/EP2026/058725）的方法，基于 PlayCanvas 3D 引擎。

该演示本身是一个 WebGL 为主的交互页面，使用 WASD 控制和鼠标拖动进行平移/旋转。视觉效果确实令人印象深刻——它通过创建一种强迫透视视图解决了传统俯视图地图失去前方上下文的问题。这是否是真正的用户体验改进，还是只是在 30 分钟通勤中可能会使用户感到疲劳的酷炫演示，尚存疑问。该公司总部位于挪威，似乎正在寻求试点和投资。

**来源：** [Orbify 演示](https://www.orbify.eu/demo/)

## 在 Apple Silicon Mac 上通过 Apple 的虚拟化框架启动虚拟 iPhone —— 360 点

vphone-cli 是一个开源工具（MIT 许可证，9.2k 星），它使用 Apple 的虚拟化框架和 PCC 研究虚拟机基础设施在 Apple Silicon Mac 上启动虚拟 iPhone。它需要 macOS 15+，Apple Silicon 芯片，以及——至关重要的是——SIP/AMFI 放松以允许使用未签名二进制文件的私有权限。这是一个重大的安全权衡，限制了其仅用于研究和开发使用。

该工具自动化了整个管道：下载 IPSW，修补启动链，DFU 恢复，安装 CFW，以及首次启动。你可以管理虚拟机（创建、克隆、导出/导入、配置 CPU/内存），并通过 Xcode 编译客端守护程序（`vphoned`）。依赖项列表相当庞大——包括 python@3.13、aria2、wget、cmake、libusb 等，反映了 iOS 启动链的复杂性。这显然是一个安全研究工具，而不是用于普通应用测试的工具。

**来源：** [vphone-cli 在 GitHub 上](https://github.com/Lakr233/vphone-cli)

## 我意外地将 LLM 内存转化为程序分析 —— 259 点

安全研究员 Jordy Zomer 在使用 LLM 代理进行漏洞研究时遇到了瓶颈：几个小时后，模型会失去对已确立事实的跟踪，建议已被排除的方法，并自信地基于无效观察进行推理。标准的 RAG 方法——嵌入旧对话，检索相关片段——没有满足需求，因为它依赖于 LLM 每次重新推导结论，而当早期观察被纠正时，这会失败。

关键的洞察：这是一个程序分析问题，而不是一个记忆问题。Zomer 建立了 Lemmalog，一个用于 LLM 的 Datalog 引擎。LLM 处理模糊提取工作（将调试器输出、源代码和自然语言转换为结构化事实），而 Datalog 处理确定性推导和——至关重要的是——自动撤销。当事实发生变化时，所有依赖的结论会自动更新，而不是需要 LLM 注意到不一致。

这确实很聪明。Datalog 的撤销问题（你不能简单地删除一个事实，如果其他推导仍然支持相同的结论）与漏洞研究中多个观察独立支持同一发现的情况完美对应。这种方法将 LLM 擅长的模糊理解与长时间会话中保持一致逻辑状态的能力区分开来。

**来源：** [我意外地将 LLM 内存转化为程序分析](https://pwning.systems/posts/llm-memory-program-analysis/)

## EVE Online 迁移到 Python 3 —— 232 点

EVE Online 的代码库自 2010 年以来一直运行在 Stackless Python 2.7 上——在同一个版本上运行了 16 年。CCP Games（现在由 Fenris Creations 所有）宣布已开始迁移到 Python 3，首次更改已部署到 Singularity 测试服务器。该游戏于 2003 年在 Stackless Python 上启动，其轻量级“任务让”让单个服务器节点能够处理数千个并发飞行员。

迁移的理由很简单：Python 2.7 在 2020 年达到了生命周期结束，现代库和工具都是 Python 3 专用的，而最近的 Python 3 发行版带来了显著的性能改进。团队的成功定义是——“它应该完全不可察觉，除了偶尔某些操作会更加流畅。”他们没有承诺从迁移中获得新功能，只是提供了一个更健康的基础。EVE 保持在 Python 2.7 上 16 年的事实要么是对 Stackless Python 稳定性的证明，要么是对技术债务积累的警告，这取决于你的视角。

**来源：** [迁移到 Python 3 开始！](https://www.eveonline.com/news/view/the-move-to-python-3-begins)

## 三星的内存计算（PIM）—— 219 点

三星在 Hot Chips 2026 上介绍了他们的 LPDDR5X-PIM，直接将 MAC（乘法-累加）单元嵌入到 DRAM 银行中。每个 16 个银行都有一个 PIM 块，可以直接访问其连接的 DRAM，而不必通过外部总线，集体利用了 614 GB/s 的内部带宽，而标准外部访问仅为 76.8 GB/s。这在计算操作中带来了 8 倍的原始带宽提升。

PIM 块支持 INT8、FP8 和 4 位格式，每块芯片在 4 位精度下可提供 2.4 TOPS。八个 LPDDR5X 芯片一起可以达到 9.6 INT8 TOPS——大致与 Intel Meteor Lake 的 NPU 相当，但需要 128 GB 的内存（八个 16 GB 芯片）。关键的设计选择是保持在标准的 LPDDR5X 协议内，因此当 PIM 不活动时，芯片可以作为正常内存使用。这是一个务实的路径——没有新的互连，也没有主机端的更改，只是计算恰好发生在数据所在之处。问题是，当离散 NPU 存在时，每个芯片的 TOPS 数字是否足以在实际工作负载中发挥作用。

**来源：** [Hot Chips 2026：三星的内存计算（PIM）](https://chipsandcheese.com/p/hot-chips-2026-samsungs-processing)

## 互联网现在有点像一个掠夺性的下水道 —— 209 点

Stephen Diehl 的文章认为，互联网从一个由人类构建的草根公共资源转变为一个“大规模制造弱点的工业系统”已经完成。欺诈经济不是外围问题——它是组织原则。平台是强化学习循环，不断在人类弱点上进行实验，优化注意力和留存。消费者、销售人员和产品已经“合并为同一个疲惫不堪的人”。

这篇文章在描述欺诈经济的参与性质时最为有力：拥有 47 个粉丝的新兴影响者是平台的免费劳动力，也是课程销售者的廉价分销渠道。附属营销人员购买了关于附属营销的课程，然后通过销售同样的课程来收回成本。生活教练培训新的生活教练。金字塔在财务上之前是社会的。Diehl 的观察——满足感是循环，痛苦是持续的收入——切中了这些系统为何难以改革的核心——它们正是按设计工作的。

**来源：** [互联网现在有点像一个掠夺性的下水道](https://www.stephendiehl.com/posts/internet_predatory_cesspit/)

## 冰川鼠 —— 203 点

冰川鼠是发现于阿拉斯加、智利、格陵兰、冰岛、斯瓦尔巴群岛、乌干达、委内瑞拉以及几个南半球岛屿上的多种苔藓的殖民地。它们形成了自由移动的球状结构，寄生着线虫、跳虫和水熊（缓步动物）。它们每天大约移动 2.5 厘米，这里有趣的是——它们的移动似乎并非随机，表现出类似群集的行为，不与风向或坡度方向相关。

目前的主导假设是：苔藓在面向太阳的一侧吸收太阳能，从而在冰融化下方形成一个小凹陷。苔藓球滚入凹陷，这一过程重复，从而产生逐渐的方向性运动（北半球向南，南半球向北）。加速度计研究证实它们实际上旋转和滚动，而不是滑动，从而在时间上暴露所有表面。它们可以持续六年至更长时间，在冰上形成自给自足的微型生态系统。首次于 1950 年由冰岛气象学家 Jón Eyþórsson 描述。

**来源：** [冰川鼠 —— 维基百科](https://en.wikipedia.org/wiki/Glacier_mice)
