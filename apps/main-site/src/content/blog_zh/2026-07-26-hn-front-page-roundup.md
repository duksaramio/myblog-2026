## 杀掉 Cookie 标识符 — 616 点

[killthecookiebanner.eu](https://killthecookiebanner.eu/)

今天最受关注的故事是一个倡导网站，推动欧盟委员会提出的提案，让浏览器能够自动传达隐私偏好，从而完全消除 Cookie 标识符。核心论点尖锐：Cookie 标识符并非因为法律要求存在，而是因为追踪行业需要你放弃从未拥有的权利。数据表明，高达90%的人在点击“接受”时实际上并不希望被追踪，只有约3%的人真正希望被追踪。

提议的解决方案简洁而优雅：你的浏览器已经能够传达你偏好的语言；为什么不传达你的隐私偏好呢？这个想法已经存在多年（如 Do Not Track、Global Privacy Control），但欧盟的数字综合改革可能会赋予它法律效力。然而，该运动本身承认，更广泛的数字综合改革包含一些有问题的条款，会削弱其他隐私权，而谷歌支持的游说活动正在多个成员国阻止这一提案。

HN 线程中的188条评论出人意料地分为“终于”和“这不会改变任何事情，因为执行才是关键问题”两种观点。两者都有道理。

## 一个冒号在 Shell 中毫无作用，但你仍然可以使用它 — 359 点

[refp.se](https://refp.se/articles/your-shell-and-the-magic-colon/)

Filip Roséen 写了一篇关于 POSIX Shell 冒号 (`:`) 的情书，这是一种不执行任何操作的空命令，但它会评估其参数。杀手级用例是用 `: "${1:?missing argument, aborting.}"` 替换四行参数验证代码——这是一个利用参数扩展和 `:?` 修饰符来在变量未设置时抛出错误信息的一行代码。

文章还深入探讨了冒号的历史，它是早期 Shell 缺乏适当流程控制时的一个工作绕过（在 `if` 语句之前，`:` 与 `goto` 风格的跳转一起使用）。它还涵盖了 `cd` 命令作为“稍微不那么无用”的兄弟——`cd` 无参数时会切换到 `$HOME`，至少有副作用。

这里的真正洞察力不在于这个技巧本身——而是 POSIX Shell 积累了几十年的这些看起来像行噪声的惯用语，但实际上是真正强大的。如果你经常编写 Shell 脚本，这篇文章值得收藏。

## GrapheneOS 对锁定设备数据提取的防护 — 322 点

[discuss.grapheneos.org](https://discuss.grapheneos.org/d/40700-grapheneos-protections-against-data-extraction-from-locked-devices)

GrapheneOS 详细介绍了其多层次防御机制，以防止物理数据提取，技术深度令人印象深刻。基础是 Android 的磁盘加密与 Pixel 的安全元素相结合，后者实现了速率限制（最多20次 PIN 尝试，失败15次后延迟增加至41天）。安全元素还具有“内部攻击抵抗力”——固件更新需要所有者认证，而不仅仅是有效的签名密钥，从而防止政府强迫进行去速率限制的更新。

GrapheneOS 进一步扩展了这一机制：密码限制从16位提高到128位（允许高熵的骰子短语），增加了第二个指纹 PIN，将生物识别尝试次数从20次减少到5次，以及一个锁定设备自动重启定时器（默认为18小时），强制设备回到“首次解锁前”状态。锁定时默认禁止 USB 数据连接。

帖子部分像是技术文档，部分像是为2027年即将与摩托罗拉合作的营销宣传。但工程是真实的——如果你认真对待设备安全，GrapheneOS 在 Pixel 上仍然是金标准。问题是，当大多数攻击者已经转向云侧提取时，这一切是否还有意义。

## 谷歌披露对 SpaceX 投资 941 亿美元，占其6%股份 — 273 点

[yahoo.com / Quartz](https://finance.yahoo.com/markets/stocks/articles/google-discloses-94-1-billion-170911535.html)

Alphabet 的第二季度财报显示，它持有价值 941 亿美元的 SpaceX 股票——约占这家最近上市公司的6%。其中，800 亿美元处于短期锁定限制中，141 亿美元将在2027年第三季度之前受限。SpaceX 于6月12日在纳斯达克（股票代码：SPCX）上市，以 135 美元/股的价格发行，其 862 亿美元的 IPO 成为历史上最大的首次公开募股。

这些数字令人震惊，但有些循环：谷歌第二季度的“其他收入”为 980 亿美元，主要是由于其对 SpaceX 股票的投资收益和另一家私人公司的投资收益。这实际上是“纸面收益，虚增了我们的季度收益”。SpaceX 最近的交易价格为 112.13 美元/股，较其发行价有所下降，使其市值约为 1.52 万亿美元。

文件中埋藏的一个更有趣的细节：谷歌和 SpaceX 正在讨论一项火箭发射协议，用于轨道数据中心，这与谷歌的 AI 基础设施野心有关。马斯克也表达了同样的兴趣。当世界上最值钱的广告公司和世界上最值钱的发射提供商开始谈论太空计算时，值得留意——即使当前的数字主要是股票市场的戏剧。

## 基于 ESP32 的桌面飞机雷达 — 251 点

[blog.ktz.me](https://blog.ktz.me/esp32-plane-radar/)

一个周末的创客项目，将 ESP32-C3 与 1.28 英寸圆形显示屏配对，创建了一个实时 ADS-B 飞机雷达。它拉取实时飞行数据，并以声纳风格的显示方式绘制附近飞机的距离和方位。构建过程大约需要15分钟，包括一些简单的焊接，通过浏览器中的 ESPHome 工具进行固件烧录。

作者（ironicbadger）对开源项目进行了修改，增加了有意义的改进：显示起始/终点信息而不是仅仅尾号，更详细的飞机类型（B737-800 vs B737），本地天气数据，以及一个基于网页的配置界面。来自 Makerworld 的 3D 打印外壳的公差太紧，不适合作者的电路板——这是社区 3D 模型常见的烦恼。

这正是让 ESP32 开发如此吸引人的项目：便宜的硬件，容易的固件更新，以及实际数据的可视化。成本约为 15 美元，它是一个桌面讨论点，真正能做点事情。GitHub 仓库目前有 33 颗星。

## 伦敦盖特威克机场推出首个机器人机场停车服务 — 231 点

[futuretravelexperience.com](https://www.futuretravelexperience.com/2026/07/london-gatwick-launches-uks-first-robotic-airport-parking-service-with-stanley-robotics/)

伦敦盖特威克机场与斯坦利机器人合作推出了英国首个机器人机场停车服务。乘客将车开入专用舱，扫描预订，将车钥匙留在车上，然后离开。自动驾驶机器人通过车轮将车辆抬起并停放在安全存储区。返回时，根据旅行细节，车辆将等待在指定舱内。

服务在南终端附近启动，提供穿梭巴士接入。斯坦利机器人首席执行官将其描述为解决“关键停车容量挑战”的方法，以应对盖特威克的增长计划。盖特威克机场负责人关于“真正的游戏改变者”的说法是标准公关，但其背后的真正价值主张是真实的：更密集的停车（机器人不需要门的间隙）、更快的周转以及没有人驾驶你的车。

HN 线程中的188条评论主要集中在故障模式上——当机器人掉落车辆、系统在高峰期宕机以及责任问题。这些都是合理的担忧。斯坦利机器人已经在里昂和其他欧洲机场部署了类似系统，所以这并非完全未经验证，但机场规模的机器人总是看起来很棒，但在事故报告中却令人恐惧。

## htmx 4.0，首个仅在 Game Boy 上发布的 JavaScript 库 — 211 点

[swag.htmx.org](https://swag.htmx.org/en-cad/products/htmx-4-the-game)

htmx，这个深受后端开发者喜爱的反框架 JavaScript 库，通过发布为 Game Boy 卡带宣布了版本 4.0。这是一个商品发布，而不是软件发布——它是一个通过 htmx 的周边商店销售的物理 Game Boy 游戏。标题是典型的 htmx 品牌：技术上准确的嘲讽，同时也是一种社区身份信号。

211 点和 75 条评论反映了 htmx 在前端生态系统中的独特地位。它是唯一一个社区积极庆祝不编写 JavaScript 的“JavaScript 库”。Game Boy 发布是一个笑话，因为它与项目的理念一致——如果你可以避免现代 web 开发的复杂性，为什么不完全复古？

这是一份周边商品，很有趣。它卖光了。

## 今天的贯穿线

今天的主要主题是 **对数字体验的控制** ——谁拥有它，谁试图夺取它，以及谁正在构建工具来重新夺回它。Cookie 标识符的故事是关于追踪行业通过 UI 暗模式制造同意。GrapheneOS 是关于防止物理访问攻击者从锁定设备中提取你的数据。Shell 冒号的文章是关于掌握你的工具而不是被它们迷惑。即使 ESP32 飞机雷达也是关于将现实世界的数据拉入你拥有并控制的设备。

谷歌/SpaceX 的披露略有不同——它关乎两家公司之间资本和能力的集中，这两家公司越来越定义互联网的基础层。轨道数据中心用于 AI 计算可能是自然的下一步，也可能是最昂贵的解决方案，寻找一个问题。时间会证明一切。

htmx Game Boy 发布是清新的调味剂：提醒我们，并非一切都需要成为平台、筹码或安全加固指南。有时候，一个游戏卡带上的笑话就足够了。
