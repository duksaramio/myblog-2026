尽管股市继续庆祝数百亿美元的人工智能订单，全球信用衍生品市场刚刚发出了一个明确的警告信号。

2026年9月26日，市场评论员Hedgie（@HedgieMarkets）发布了一张来自彭博社和《金融时报》的图表，迅速在交易台上传播开来：

> “甲骨文5年期信用违约互换利差刚刚创下230个基点的历史新高，是更广泛的55个基点投资级指数的四倍。在过去一年中，利差已经翻了四倍，并且超过了2008年金融危机的水平。以土耳其主权信用违约互换245个基点为比较，甲骨文的信用风险被定价为比现代历史上最严重的金融危机还要高。”

![甲骨文5年期CDS利差飙升与CDX IG指数](/oracle-cds-spread-spike-2026.png)

信用市场以无情著称。而股权分析师根据乐观的多年的折现率和管理层指导的总可寻址市场（TAM）来定价增长，而信用违约互换（CDS）交易员则仅根据一个指标进行交易：**违约和资本回收的数学概率**。

当一家拥有超过1250亿美元总债务的遗产技术巨头看到其CDS利差从40个基点飙升至230个基点——与更广泛的市场背道而驰时，这并非噪音。这是债券市场在定价结构性流动性危机。

甲骨文股价飙升的背后，存在三个生死攸关的力量的交汇点：
1. **标普评级下调至BBB-**：将甲骨文置于投机级（垃圾级）的边缘，一个单一的评级下调将触发**有史以来最大的强制性抛售，规模达数千亿美元**。
2. **OpenAI的极端对手方集中度**：甲骨文6380亿美元剩余绩效义务（RPO）中近50%与一个亏损的AI初创公司相关，该公司预计到2030年累计现金赤字为2780亿美元。
3. **“太大而不能倒”的国家安全赌博**：拉里·埃里森似乎押注甲骨文在五角大楼、情报机构和医疗基础设施中的深厚渗透确保了在AI基础设施周期破裂时会获得联邦救助。

让我们对信用机制、对手方敞口、堕落天使传导机制以及这对更广泛的人工智能宏观经济周期意味着什么进行法医式的拆解。

## 1. 解剖信号：230个基点的CDS利差意味着什么

要理解图表的规模，必须了解信用违约互换（CDS）的功能以及投资级技术债务的典型估值方式。

信用违约互换是一种场外金融衍生品，功能上类似于对冲公司或主权违约的保险。230个基点的利差意味着机构债券持有者必须每年支付230,000美元来为1000万美元的甲骨文债务提供违约保险，为期5年（年化2.3%）。

```
5年期CDS利差比较（2026年9月）
-----------------------------------------------------------------------------------------
资产/发行人                           5年期CDS利差    信用评级（标普/穆迪）
-----------------------------------------------------------------------------------------
微软公司（MSFT）                   ~18个基点         AAA / Aaa
谷歌公司（GOOGL）                  ~22个基点         AA+ / Aa2
Markit CDX北美投资级指数           55个基点          投资级综合指数
美国高收益“BB”交叉指数           ~210 - 240个基点  高收益 / 投机级
甲骨文公司（ORCL）                230个基点         BBB- / Baa3（负面展望）
土耳其共和国（主权）               245个基点         B / B1（投机级主权）
-----------------------------------------------------------------------------------------
```

### 三个令人担忧的背离

1. **四倍于CDX指数的背离**：Markit CDX北美投资级指数代表了125家流动性良好的北美投资级发行人篮子。2026年9月，该指数平静地停留在55个基点，反映了健康的宏观经济流动性以及可控的系统性压力。甲骨文的230个基点CDS利差是其同行基准的4.18倍。这不是宏观经济贝塔；而是特定资产负债表的困境。

2. **超过2008年全球金融危机水平**：在2008年雷曼兄弟崩溃的最深处，全球信贷市场完全冻结，银行系统中的对手方风险激增。甲骨文5年期CDS曾短暂超过100-120个基点。今天，230个基点的信用衍生品交易员认为甲骨文的违约风险**超过了现代历史上最严重的金融危机期间的峰值恐慌水平的两倍**。

3. **与土耳其主权债务相当**：土耳其是一个新兴市场经济体，历史上外汇储备波动剧烈、通货膨胀率两位数、主权评级为投机级B/B1（245个基点）。固定收益市场要求为甲骨文公司债务提供与土耳其主权债务相同的违约风险溢价，这表明债券交易商严重不信任甲骨文的资产负债表杠杆。

## 2. 1250亿美元的“堕落天使”陷阱

为什么市场如此恐慌，尽管甲骨文仍然被技术上归类为“投资级”？

答案在于**BBB-与BB+之间的流动性悬崖**。

```
投资级（IG）               高收益（“垃圾级”）
+-----------------------------+     +-----------------------------+
| AAA  |  AA  |   A   |  BBB  |  |  |  BB+  |   BB   |    B   | CCC |
|                             |  |  |                             |
| 机构（养老金/保险公司）管理的  |  |  | 家庭办公室、困境债务  |
| 千万亿资金的法定或信托章程  |  |  | 严格禁止持有非投资级债务  |
+-----------------------------+  |  +-----------------------------+
                                 |
                                 v
                     BBB-流动性悬崖
                     （甲骨文目前：BBB-）
```

### 2026年7月标普评级下调
2026年7月9日，标普全球评级将甲骨文长期发行人信用评级从**BBB下调至BBB-**，维持**负面展望**。

BBB-是最低的投资级评级。在评级下调声明中，标普信用分析师指出他们**低估了支持大规模人工智能扩张所需的资本投资和债务融资基础设施建设规模**。

标普预计甲骨文的债务与息税前利润（EBITDA）杠杆率将在2027财年中期保持在中等4倍左右——远高于稳定投资级评级所需的2.5倍至3.0倍的上限。

### 强制性抛售的机制
在公司金融中，“堕落天使”是指从投资级（BBB-或更高）被下调至投机级（BB+或更低）的发行人。

这一转变不仅仅是字母的变化；它触发了机构机械抛售：
* **受监管的投资委托**：由主权财富基金、州养老金系统（如CalPERS）、企业退休计划和人寿保险公司管理的数万亿美元资金有严格的法定或信托章程，**明确禁止持有非投资级债务**。
* **指数剔除**：全球固定收益的核心基准——**彭博美国综合债券指数（“The Agg”）**，以及大型ETF如先锋总债券市场（BND）和iShares投资级公司债券ETF（LQD）——必须在每月再平衡周期结束时自动剔除任何低于BBB-/Baa3的债券。
* **抛售的规模**：截至2027财年第一季度（截至2026年8月31日），甲骨文持有约**1253亿美元的总表内债务**（长期票据1177亿美元，短期债务7.6亿美元），调整后的租赁包括在内后债务总额可能达到**1435亿美元**。

```
历史上堕落天使比较（按债务规模）
-----------------------------------------------------------------------------------------
公司                 降级至垃圾级年份    预估债务降级规模
-----------------------------------------------------------------------------------------
通用汽车（GM）     2005年              约300亿美元
欧佩克石油公司    2020年              约350亿美元
福特汽车公司      2020年              约360-780亿美元
甲骨文公司（潜在） 2026年/2027年      约1250亿美元以上（创纪录）
-----------------------------------------------------------------------------------------
```

如果标普或穆迪将甲骨文下调一个等级至BB+，甲骨文将立即成为**有史以来最大的单个堕落天使**。

美国高收益债券市场的总市值约为1.4万亿美元至1.6万亿美元。将**1250亿美元以上的甲骨文债券一夜之间抛入垃圾债券市场**，将代表一个相当于整个资产类别的8%至10%的供应冲击。高收益共同基金和ETF的流动性无法吸收如此大规模的供应，除非二级市场债券价格暴跌至70-80美分，导致所有投机级公司的借贷成本飙升。这就是为什么CDS利差飙升的原因：衍生品交易员正在提前预判强制性抛售悬崖。

## 3. 对手方定时炸弹：OpenAI的2780亿美元烧钱

如果甲骨文的债务负担如此脆弱，为什么拉里·埃里森还要加速？

催化剂是争夺人工智能云战争的竞赛。亚马逊（AWS）、微软（Azure）和谷歌（GCP）在传统企业云托管中占据主导地位，甲骨文云基础设施（OCI）定位为低开销的AI计算集群供应商——与OpenAI、软银和埃隆·马斯克的xAI签署了一系列重大合作协议。

在最近的财报电话会议上，甲骨文庆祝其剩余绩效义务（RPO）创纪录的6380亿美元订单，股价飙升。

然而，信用评级机构会忽略这些头条订单，来评估**客户集中度和对手方的偿付能力**。

### 对手方脆弱性的解剖

1. **50%的订单集中在单一实体**：根据标普的评估，**OpenAI约占甲骨文6380亿美元RPO订单的50%**。这意味着甲骨文未来数年的大部分收入都依赖于OpenAI这家单一公司的财务生存和合同偿付能力。

2. **OpenAI的2780亿美元现金赤字现实**：在OpenAI计划进行公司重组和IPO前的资本筹集之前，内部财务数据显示OpenAI预计到2030年累计自由现金流亏损2780亿美元。为了维持其前沿模型训练和推理管道，OpenAI预计需要**8560亿美元的总计算和基础设施支出**。

3. **致命的不对称性**：
   * **甲骨文的义务是硬性和刚性的**：当甲骨文与电力供应商签署15至20年的电力购买协议（PPA），租赁数千英亩的工业用地，并下达数亿美元不可取消的NVIDIA黑威尔（GB200/B300）集群采购订单时，这些负债是固定的公司债务和租赁条款。
   * **OpenAI的支付能力是投机性和可变的**：OpenAI的付款依赖于全球主权财富基金和风险投资家的连续、不间断的数亿美元融资轮次。

如果风险资本的风险偏好减弱，或者模型能力的提升面临边际收益递减，导致企业订阅增长放缓，OpenAI将被迫重新谈判、推迟或违约其计算预订。

如果OpenAI无法按时支付，甲骨文将持有大量专门的、快速贬值的硬件，数百亿美元的每月电力和公用事业承诺，以及一个没有相应现金流来偿还的1250亿美元债务堆。

## 4. “太大而不能倒”的赌注：埃里森的政府保护

在病毒式评论中，Hedgie指出了埃里森心态的心理基础：

> “我认为他假设甲骨文太大且太嵌入政府IT系统，不能被允许倒闭。这可能最终会实现，但这是一种赌注，即有人会承担下行风险，而不是一种金融策略。”

埃里森是痴人说梦，还是在计算主权保护？

甲骨文在美联邦政府核心操作体系中的整合几乎无法夸大：
* **五角大楼（JWCC）**：甲骨文是国防部价值90亿美元的联合战争云能力合同下的四个授权多云提供商之一，为战术边缘计算和最高机密的国防操作提供动力。
* **情报机构**：甲骨文政府云为中央情报局、国家安全局和国家情报总监托管机密工作负载。
* **医疗基础设施（Cerner）**：甲骨文以280亿美元收购Cerner，直接将退伍军人事务部（VA）和国防部医疗系统的电子健康记录置于甲骨文服务器上。
* **福利发放**：社会保障署、医疗保险和税务机构运行的事务关系数据库引擎运行在甲骨文硬件和软件上。

埃里森的论点似乎很清楚：**美国政府不能让甲骨文关门**。如果甲骨文的数据中心破产，将瞬间瘫痪国防物流、退伍军人医疗和联邦税务征收。

### 为什么“太大而不能倒”不能拯救债券持有人或股东

“太大而不能倒”（TBTF）论点的关键缺陷在于混淆了**运营的保存**与**资本的保存**。

历史为投资者在联邦救助上的赌注提供了严酷的教训：
1. **通用汽车和克莱斯勒（2009年）**：通用汽车被视为美国工业基础的关键。联邦政府通过数十亿美元的TARP融资介入。生产线从未停止，汽车工人继续生产汽车。然而**股票被清零**，高级无担保债券持有人被迫在结构化的第11章重组中接受大幅减记。
2. **房利美和房地美（2008年）**：抵押巨头是美国住房所有权的支柱。政府将它们置于永久托管。抵押贷款得到了支付，但普通股东几乎被清零，优先股价值下降了90%以上。

即使在最慷慨的救助情景下，如果甲骨文面临债务危机，国防部门将介入以接管或保护其**军事数据库和国家安全云区域**。

白宫不会花费数百亿美元的纳税人资金来服务为构建OpenAI的投机GPU集群发行的私人公司债券。

## 5. 连接点：人工智能债务超级周期

这一发展必须与我们对高盛2026年9月关于**超大规模人工智能资本支出**的报告的早期调查一起考虑。

在该分析中，我们记录了六家主要基础设施运营商在第二阶段人工智能资本支出（1.22万亿美元）上每年3080亿美元的收入门槛，以在5年的残酷折旧周期中实现0.0%的内部收益率（ROIC）。

```
人工智能资本周期的演变
-----------------------------------------------------------------------------------------
第一阶段（2023-2024）：现金流收割
- 参与者：微软、谷歌、Meta、苹果。
- 资金：100%通过大规模搜索、广告和软件自由现金流自筹。
- 杠杆：零净债务；资产负债表类似于主权堡垒。
- 市场反应：机构共识性狂喜。

第二阶段（2025-2026）：杠杆化土地抢夺
- 参与者：甲骨文、CoreWeave、新兴云初创公司、公用事业合资企业。
- 资金：高收益银团贷款、私人信贷、商业票据、大规模债券发行。
- 杠杆：债务与息税前利润（EBITDA）比率上升至4-5倍；客户集中度在现金烧钱初创公司。
- 市场反应：CDS利差飙升；标普评级下调；债券市场提前预判违约。
-----------------------------------------------------------------------------------------
```

在第一阶段，人工智能热潮由大科技的现金奶牛资助。微软和谷歌可以每年从多余的运营现金流中支付数十亿美元的GPU费用，而不必承担债务。

在第二阶段，竞赛从数兆瓦扩展到**兆瓦级超大规模数据中心**。为了在万亿级资产负债表中保持相关性，甲骨文选择了通过**杠杆**来融资建设。

甲骨文230个基点的CDS利差是第二阶段达到其财务极限的明确信号。固定收益投资者拒绝以投资级价格为下一波投机GPU基础设施提供资金。

| **标普/穆迪评级行动** | 低于BBB-/Baa3 | **堕落天使事件**：触发估计500亿至800亿美元的机构强制性抛售，来自投资级债券基金。 |
| **甲骨文5年期CDS利差** | 跨过300个基点 | 价格预示即将进行债务重组；债券市场实际上关闭了新的未对冲债务发行。 |

| **OCI订单（RPO）现金转换** | RPO转化为收入的实现率 | 检查6380亿美元订单是否转化为实际的GAAP经营现金流，还是仍然只是未实现的纸面订单。 |
| **高收益二级市场利差** | 美国高收益指数与甲骨文债券之间的利差 | 测量高收益债务基金是否愿意吸收甲骨文债券，还是要求折价收益率（10%以上）。 |

## 结论：金丝雀已歌唱

历史上，信用市场是最聪明的钱。

2007年，股市创历史新高，而ABX次级抵押贷款指数和贝尔斯登信用违约互换正在发出红色警报。2001年电信崩溃前，世界通信和全球交叉的信用利差在公司破产重写光纤行业前几个月就已飙升。

今天，股权投资者看到甲骨文的头条订单，看到了人工智能超高速增长引擎。但信用违约互换交易员看到的是**1250亿美元的公司债务、标普评级接近垃圾边缘，以及一个亏损的初创公司占据了订单簿的一半**。

在230个基点的水平上，人工智能矿井中的金丝雀不仅在鸣叫。它正在喘息。
